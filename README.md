# Hoja de vida · Johan Stiven Rodriguez Triana

Sitio web personal con mi hoja de vida profesional. Desarrollado como trabajo colaborativo de la materia **Introducción a los lenguajes de Internet** (Ingeniería de Software).

**Sitio publicado:** https://johans123.github.io/hoja-de-vida/

## Páginas

| Página | Contenido |
|---|---|
| `index.html` | Presentación y perfil profesional |
| `experiencia.html` | Experiencia laboral, línea de tiempo y tabla de cargos |
| `educacion.html` | Estudios y certificaciones |
| `habilidades.html` | Habilidades técnicas por categoría y competencias |
| `contacto.html` | Datos de contacto y formulario |

## Estructura

```
hoja-de-vida/
├── index.html
├── experiencia.html
├── educacion.html
├── habilidades.html
├── contacto.html
├── css/styles.css
└── img/
    ├── avatar.svg
    └── fondo.svg
```

## Tecnologías

- HTML5 semántico
- CSS3 (variables, grid, diseño responsive)
- GitHub Pages como hosting

## Ejecutar en local

No requiere instalación. Clona el repositorio y abre `index.html` en el navegador:

```bash
git clone https://github.com/johanS123/hoja-de-vida.git
```
